Jarvis World Quick start

A voice AI assistant for your computer

Jarvis World is the open-source home of Jarvis Live. Run it on your computer, talk to it in real time, and hand tasks to the coding agents you already use.

View on GitHub

Real-time conversation

Speak with Gemini Live or OpenAI Realtime, with support for interrupting Jarvis as it answers.

Coding agents

Send requests to tools such as Claude Code and Codex, then follow their progress in the dashboard.

Optional live avatar

Use a lip-synced talking avatar in the browser with the AVTR-1 renderer on a supported NVIDIA GPU.
